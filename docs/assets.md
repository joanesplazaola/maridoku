# Recursos visuales

Todos los bitmaps distribuidos por el proyecto fueron generados para Maridoku
con las herramientas de imagen de OpenAI o derivados localmente de esos
resultados. No se incluyen recursos de stock ni arte de Murdoku.

`assets-manifest.json` registra la ruta, el SHA-256, el commit de entrada y la
procedencia de cada archivo. La prueba de contrato obliga a actualizar ese
registro cuando se añade o modifica un recurso.

La base de uso es la propiedad del output indicada en los
[Términos de uso de OpenAI](https://openai.com/policies/terms-of-use/), vigentes
desde el 1 de enero de 2026. La procedencia no sustituye una comprobación de
marcas o similitud antes de una campaña comercial.
